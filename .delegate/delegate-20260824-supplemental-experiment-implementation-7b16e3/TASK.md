## 任务目标

在不改变冻结主分析、冻结角膜处方、冻结 IOL 载体、基础模型眼、生产频率尺度和既有证据的前提下，为《角膜老视矫正_EDOF_IOL_补充实验方案》实现一个可审查、可测试、默认不伪造光学数据的补充实验软件层。

本任务将附件文档视为实验设计说明；实际执行仍受本任务契约、仓库现有冻结规则和用户指定分工约束。附件中的实验结论、预期趋势和“建议”不能被实现为预设结果。

## 必须覆盖的实验契约

1. 原 96 配置的补充贯焦网格为 `+1.00 D` 到 `-5.00 D`，步长 `-0.125 D`，恰好 49 个平面；远焦峰值搜索范围为 `[-1.00 D, +1.00 D]`。
2. 新增分支只覆盖中央近用径向多焦角膜，恰好 24 个配置：2 基础眼 × 3 IOL 机制 × 2 IOL 状态 × 2 瞳孔。
3. 新分支必须显式记录“距离成分锚定”策略：只在求解基础 IOL 度数和机制特异基础球差时把中央 `+1.75 D` 近附加置零；随后冻结度数、曲率、非球面、厚度、材料、位置和载体；恢复近附加后禁止再次求度数、自动对焦、重新定焦或载体再优化。
4. 匹配 MONO/EDOF 必须共享同一冻结载体，EDOF 与 MONO 的唯一状态差异是延焦结构。
5. 只从已生成的补充贯焦数据派生：相对 30%/50%/70% 焦深、未治疗参照单焦的共同阈值、30 cycles/degree 贯焦曲线、逐基础眼/瞳孔/机制的差中差。删失必须显式传播为状态或区间，不能用插值之外的数值补齐边界删失。
6. `-5.00 D` 仍是边界时报告删失，不允许因删失自动扩展到 `-6/-8/-10 D`。
